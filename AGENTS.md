# Project requirements

- Work in this existing project; do not read or modify `prompt/`.
- For game images and maps, use original Wobbly Life imagery only. This is an explicit user correction.
- Do not invent, generate, trace, or redraw game maps or substitute schematic artwork.
- Prefer assets published directly by RubberBandGames. Unmodified in-game screenshots must retain their provenance and be identified honestly as community screenshots where applicable.
- Record image sources in `ASSETS.md`; do not claim community uploads were published by the developer.
- Preserve the independent fan-project identity and disclaimer.
- Keep normalized markers aligned to the actual image. Never reuse coordinates from a different map without migration or recalibration.
- The player's location is manual in-game data only. Never request real device location.
