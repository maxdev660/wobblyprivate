# Image policy / Bildvorgabe

User requirement: use original Wobbly Life imagery for maps and game illustrations. Never generate, trace, redraw or substitute a schematic map. Generic UI controls and the independent fan-project brand are not game screenshots.

Nutzervorgabe: Für Karten und Spielabbildungen ausschließlich Originalmaterial aus Wobbly Life verwenden. Keine generierten, nachgezeichneten oder schematischen Ersatzkarten. Allgemeine Bedienelemente und die eigenständige Fan-Projekt-Marke sind keine Spielbilder.

## Requested wiki map (17 October 2026)
https://wobblylife.wiki.gg/wiki/Presents could not be fetched: HTTP 403 / Cloudflare challenge in both web reader and normal Edge. No map file was extracted or substituted. The UI links directly to the requested interactive map; existing local screenshots remain clearly identified.

Collection location facts were compared against Presents, Secrets and Steam guide 3640386662. The Presents list inconsistently marks the crystal pet as uncounted, whereas Secrets and the text guide identify the final crystal ship as the bonus. The 50-entry checklist follows the latter interpretation. Descriptions are rewritten; no guide images were copied from the text guide.
